# Sign-Language Classifier

A Jupyter-notebook machine-learning project based on a sign-language image dataset. The repository contains the notebook and selected supporting assets.

## Run

Create a Python environment, install the notebook's dependencies, start Jupyter, and run the notebook from top to bottom. Keep large datasets out of Git unless they are licensed for redistribution; provide their source and download instructions instead.
